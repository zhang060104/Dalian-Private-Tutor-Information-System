# Dalian-Private-Tutor-Information-System

大连私人家教信息系统（家教信息门户）

## 项目结构

```
├── front_end/   # 官网前端（Vue3 + Vite + Element Plus）
│   ├── README.md  # 前端说明（技术栈 / 命令 / 结构 / 对接指引）
│   └── DEVLOG.md  # 前端开发日志（只增不删）
└── DEVELOPER_LOG.md  # 开发者入驻与协作日志（只增不删）
```

## 协作规范

- 前端改动走 `feature/xxx` 分支 + PR 合并，禁止直推 main
- DEVLOG 只增不删，改动后同步追加记录并提交
